# 🐍 Python Learning Journey

## 📅 Day 1 — What I Learned

Today I learned 3 topics:

1. Variable
2. input()
3. type()

---

## 1. Variable

### Definition

A variable is a name used to store a value.

### Example

```python
name = "Nayan"
age = 20

print(name)
print(age)
```

---

## 2. input()

### Definition

input() is used to get information from the user while the program is running.

### Example

```python
name = input("What is your name? ")

print(name)
```

---

## 3. type()

### Definition

type() is used to find out what type of data a variable contains.

### Example

```python
age = 20

print(type(age))
```

Output:

```text
<class 'int'>
```

---

## 🧠 Quick Revision

- **Variable** → stores a value
- **input()** → gets information from the user
- **type()** → tells us the data type
